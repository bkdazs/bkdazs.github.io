# Power of Attorney: Types, Uses, and Risks

A Power of Attorney (POA) is one of the most powerful legal documents you can create. It allows someone else to act on your behalf for financial, legal, or personal matters. But this power can be misused. This guide explains everything you need to know.

## What Is Power of Attorney?

### Definition

```
Power of Attorney:
- Legal document
- Authorizes someone (Agent) to act
- On behalf of another (Principal)
- For specified or general purposes
- Can be limited or broad in scope
```

### Key Terminology

| Term | Meaning |
|------|---------|
| Principal | Person granting power |
| Agent/Attorney | Person receiving power |
| POA | Power of Attorney document |
| Donor | Same as Principal |
| Donee | Same as Agent |

### Legal Basis

```
Governed By:
- Powers of Attorney Act, 1882
- Indian Stamp Act
- Registration Act, 1908

Key Points:
- Must be in writing
- Stamp duty applicable
- Registration needed for immovable property
```

## Types of Power of Attorney

### 1. General Power of Attorney (GPA)

```
Scope: Very Broad

Covers:
- All financial matters
- Property transactions
- Legal proceedings
- Business operations
- Banking activities
- Everything on behalf of principal

When Used:
- NRIs managing property in India
- Extended absence
- Business delegation
- Elderly parents' affairs
```

### 2. Special Power of Attorney (SPA)

```
Scope: Limited to Specific Purpose

Example Uses:
- Sell specific property
- Operate one bank account
- Represent in one court case
- Sign one contract

Advantage:
- Limited risk
- Specific control
- Expires on completion
```

### 3. Durable Power of Attorney

```
Special Feature:
- Remains valid if principal becomes incapacitated
- "Survives" mental disability
- Must explicitly state durability

Regular POA:
- Becomes void if principal incapacitated
- Agent loses authority
- New arrangement needed

Durable POA:
- Continues despite incapacity
- Essential for elderly planning
- Healthcare decisions possible
```

### 4. Medical/Healthcare POA

```
Purpose:
- Healthcare decisions
- If principal cannot decide
- Life-sustaining treatment choices
- Medical procedure consents

Also Called:
- Healthcare proxy
- Medical directive
- Healthcare surrogate
```

### 5. Springing Power of Attorney

```
Special Feature:
- Becomes effective only on trigger event
- Usually incapacity of principal
- "Springs" into action when needed

Example:
POA effective only when:
- Principal declared incapacitated by doctor
- Principal hospitalized for X days
- Specific condition occurs
```

## Creating a Valid POA

### Essential Elements

```
Required Contents:
1. Title (General/Special POA)
2. Date of execution
3. Principal's full details
4. Agent's full details
5. Specific powers granted
6. Limitations (if any)
7. Duration
8. Signatures
9. Witnesses (2)
10. Notarization
11. Registration (if required)
```

### Execution Process

```
Step-by-Step:

Step 1: Draft POA
- Legal language
- Specific powers
- Clear boundaries

Step 2: Stamp Duty
- Pay applicable stamp duty
- Varies by state
- Depends on property value (for GPA)

Step 3: Execution
- Principal signs
- Two witnesses sign
- Before notary public

Step 4: Notarization
- Notary verifies identity
- Notary stamps and signs
- Creates record

Step 5: Registration (if needed)
- For immovable property
- At Sub-Registrar office
- Both parties present
```

### For NRIs

```
Special Process:
1. Execute POA abroad
2. Before Indian consulate/embassy
3. Or before local notary
4. Get apostille (if applicable)
5. Send to India
6. Adjudication for stamp duty
7. Registration if needed
```

## Limitations and Restrictions

### Cannot Delegate

```
Principal Cannot Give Power To:
- Make a will
- Vote in elections
- Take oath on behalf
- Actions requiring personal presence
- Marry on behalf
- Adopt children (with exceptions)
```

### Fiduciary Duty

```
Agent Must:
- Act in principal's interest
- Maintain records
- Not mix personal/principal funds
- Act within granted powers
- Not profit personally
- Keep principal informed
```

## Stamp Duty and Registration

### Stamp Duty

```
General Rule:
- Payable on all POAs
- Rates vary by state
- Higher for property-related POAs

Typical Rates:
- Simple POA: ₹100-500
- GPA for property: % of property value
- Can be significant for valuable property
```

### Registration Requirement

```
Mandatory Registration:
- POA for immovable property sale
- Creating interest in property
- Per Registration Act, 1908

Optional Registration:
- Other POAs
- But recommended for safety
```

### State Variations

| State | GPA Stamp Duty (Property) |
|-------|--------------------------|
| Delhi | 3% of property value |
| Maharashtra | ₹500 |
| Karnataka | 5% of value |
| Tamil Nadu | 4% of value |

*Rates change - verify current rates*

## Risks and Misuse

### Risk 1: Property Fraud

```
Common Scam:
- Agent sells property without authority
- Or exceeds POA limits
- Fake POAs used
- Principal unaware

Protection:
- Use SPA, not GPA
- Limit to specific property
- Set time limits
- Inform family/neighbors
```

### Risk 2: Financial Abuse

```
Common Misuse:
- Agent withdraws all funds
- Creates debts in principal's name
- Diverts investments
- Changes beneficiaries

Protection:
- Regular account monitoring
- Limit financial powers
- Multiple oversight
- Bank notifications
```

### Risk 3: Unauthorized Actions

```
Examples:
- Acting beyond scope
- Continuing after revocation
- Self-dealing
- Conflicts of interest

Protection:
- Clear power limits
- Written scope
- Regular reviews
- Quick revocation if issues
```

### Risk 4: Elderly Abuse

```
Scenario:
- Elderly person gives POA
- Agent takes advantage
- Incapacity prevents oversight
- Assets depleted

Protection:
- Trusted family member as agent
- Co-agents requirement
- Third-party oversight
- Springing POA
```

## Choosing the Right Agent

### Qualities to Look For

```
Ideal Agent:
□ Trustworthy
□ Financially responsible
□ Available when needed
□ Understands your wishes
□ No conflicts of interest
□ Competent for the task
□ Good record-keeping
□ Communicative
```

### Who to Avoid

```
Don't Choose:
✗ Someone with financial problems
✗ Person you barely know
✗ Those who might benefit from misuse
✗ Someone too busy
✗ Person with legal issues
✗ Anyone you don't fully trust
```

### Multiple Agents

```
Options:
1. Joint Agents (must act together)
   - More oversight
   - Can be cumbersome
   
2. Successive Agents (one after another)
   - If first unable, second steps in
   
3. Different Agents for Different Matters
   - One for property
   - Another for finances
   - Limits risk
```

## Revocation of POA

### When to Revoke

```
Revoke Immediately If:
- Agent acting improperly
- Relationship breakdown
- Agent incapacitated
- No longer needed
- Principal regains capacity (springing)
- Task completed (SPA)
```

### How to Revoke

```
Process:
1. Draft revocation deed
2. Same formalities as POA
3. Notify agent in writing
4. Notify all third parties
5. Register revocation (if POA registered)
6. Public notice recommended
7. Retrieve original POA if possible
```

### Automatic Termination

```
POA Ends When:
- Principal dies
- Agent dies
- Task completed
- Time period expires
- Principal revokes
- Principal incapacitated (unless durable)
- Court terminates
```

## POA vs. Other Documents

### POA vs. Will

| Aspect | POA | Will |
|--------|-----|------|
| Effective | During life | After death |
| Purpose | Act on behalf | Distribute estate |
| Revocable | Yes | Yes |
| Ends on death | Yes | Comes into effect |

### POA vs. Nomination

| Aspect | POA | Nomination |
|--------|-----|------------|
| Purpose | Authority to act | Claim after death |
| Timing | During life | After death |
| Scope | Broad powers | Specific asset |

### POA vs. Guardianship

| Aspect | POA | Guardianship |
|--------|-----|--------------|
| How created | Voluntary | Court appointed |
| When | Before incapacity | After incapacity |
| Flexibility | High | Court supervised |
| Cost | Low | Higher |

## Practical Tips

### Creating POA

```
Do's:
✓ Be specific about powers
✓ Include limitations
✓ Set time limits
✓ Use springing for incapacity
✓ Get legal advice
✓ Keep certified copies
✓ Inform third parties

Don'ts:
✗ Give blank POA
✗ Grant unnecessary powers
✗ Choose untrustworthy agent
✗ Forget to register if needed
✗ Leave POA with agent only
```

### Managing Existing POA

```
Regular Review:
□ Annual assessment
□ Check agent's actions
□ Verify no misuse
□ Update if needed
□ Revoke if concerned
```

### If You're an Agent

```
Responsibilities:
- Act only within powers
- Keep detailed records
- Act in principal's interest
- Report regularly
- Don't mix funds
- Seek guidance if unsure
- Return records when done
```

## Conclusion

Power of Attorney is essential for managing affairs when you can't be present or capable. But it's also easily misused. The key is choosing the right type of POA, the right agent, and maintaining oversight.

**Key Takeaways:**

1. **Use SPA over GPA**—limit powers when possible
2. **Choose agent carefully**—trust is paramount
3. **Be specific**—detail exact powers granted
4. **Set limits**—time, amount, scope
5. **Register when required**—especially for property
6. **Monitor regularly**—don't set and forget
7. **Revoke quickly if needed**—don't delay
8. **Consider durable POA**—for incapacity planning

A well-drafted POA protects you; a careless one exposes you to significant risk.
