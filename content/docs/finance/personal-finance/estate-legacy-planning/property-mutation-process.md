# Property Mutation Process in India

Property mutation is the process of updating ownership records in government revenue records after a property changes hands. This is essential for establishing clear title and paying property tax in the new owner's name.

## What Is Property Mutation?

### Definition

```
Property Mutation:
Recording change of ownership in:
- Land revenue records
- Municipal records
- Property tax records

Also Called:
- Dakhil Kharij
- Mutation of property
- Title transfer in records
```

### What Gets Updated

```
Records Changed:
- Record of Rights (RoR)
- Khata/Khatauni
- Property tax register
- Municipal records
- 7/12 extract (Maharashtra)
- Patta (Tamil Nadu)
- Jamabandi (Punjab/Haryana)
```

### Why Mutation Is Important

```
Necessary For:
- Property tax payment
- Proof of ownership
- Future sale
- Loan against property
- Construction permissions
- Utility connections
- Government subsidies
```

## When Is Mutation Required?

### Common Scenarios

```
Mutation Needed After:
1. Purchase (sale deed)
2. Inheritance (death of owner)
3. Gift
4. Partition
5. Court decree
6. Exchange
7. Foreclosure/auction
```

### Registration vs. Mutation

```
Registration (Sale Deed):
- Transfers legal ownership
- Creates title document
- Done at Sub-Registrar

Mutation (Revenue Records):
- Updates government records
- For tax and record purposes
- Done at Tehsil/Municipal office

Both Are Separate Steps!
```

## Types of Mutation

### By Sale/Purchase

```
Process After Buying:
- Based on registered sale deed
- Buyer applies
- Straightforward process
- Usually faster
```

### By Inheritance

```
Process After Death:
- Based on succession
- Legal heir applies
- May need succession certificate
- Or legal heir certificate
- Can be complex if disputes
```

### By Gift

```
Process After Gift:
- Based on registered gift deed
- Donee applies
- Similar to sale mutation
```

### By Partition

```
Process After Partition:
- Based on partition deed
- Or court decree
- Each share holder applies
```

## Documents Required

### For Sale-Based Mutation

```
Essential Documents:
□ Application form
□ Registered sale deed
□ Previous ownership documents
□ Latest property tax receipt
□ Identity proof of applicant
□ Encumbrance certificate
□ Survey/measurement documents
□ Photos (if required)
```

### For Inheritance-Based Mutation

```
Additional Documents:
□ Death certificate
□ Legal heir certificate
  OR Succession certificate
□ Relationship proof
□ NOC from other heirs
□ Affidavit (if applicable)
□ Will and probate (if exists)
```

### For Gift-Based Mutation

```
Required Documents:
□ Registered gift deed
□ Donor's consent
□ Tax payment receipts
□ ID proof of donee
```

## Application Process

### Step 1: Gather Documents

```
Collect:
- All relevant documents
- Certified copies
- Notarized affidavits if needed
- Latest tax receipts
```

### Step 2: Submit Application

```
Submit To:
- Tehsildar (rural areas)
- Municipal Corporation (urban)
- Nagar Palika
- Panchayat office

Application Includes:
- Filled form
- Supporting documents
- Processing fee
```

### Step 3: Field Verification

```
Official Action:
- Patwari/Revenue Inspector visits
- Verifies possession
- Checks documents
- Prepares report
```

### Step 4: Notice Period

```
Public Notice:
- Notice published
- Objection period (15-30 days)
- Anyone can object
- Notice at property (sometimes)
```

### Step 5: Final Order

```
After No Objection:
- Tehsildar/Officer approves
- Mutation order issued
- Records updated
- New extract available
```

## Timeline and Fees

### Expected Time

```
Typical Timeline:
- No objection: 30-60 days
- If objection: Several months
- Complex cases: 6 months+

Factors:
- Document completeness
- Officer workload
- Objections
- Verification time
```

### Government Fees

```
Typical Fees:
- Application fee: ₹50-500
- Processing fee: Varies
- Total: ₹100-1,000 usually

No Stamp Duty:
Mutation itself doesn't attract stamp duty
(That's paid during registration)
```

## Common Issues and Solutions

### Delayed Processing

```
Causes:
- Incomplete documents
- Pending objections
- Staff shortage

Solutions:
- Follow up regularly
- Ensure complete documentation
- Escalate to higher authority
- RTI if excessive delay
```

### Objections Filed

```
By Whom:
- Other claimants
- Previous owners
- Adjacent property owners

Process:
- Inquiry held
- Evidence examined
- Decision by officer
- Appeal if rejected
```

### Missing Documents

```
Common Gaps:
- Old ownership records
- Previous sale deeds
- Partition documents

Solutions:
- Search in registry
- Revenue record copies
- Affidavit about loss
- Court declaration
```

### Joint Property

```
Issues:
- All owners should apply
- Or consent required
- Different addresses

Solution:
- Coordinate with co-owners
- Collective application
- POA if someone abroad
```

```
Process:
```

```
2. Village Accountant inquiry

```

### Tamil Nadu

```
Process:
1. Apply at Taluk office

4. Patta issued

```

```
For Urban Property:
1. Apply to MCD/NDMC
```

## Special Situations

### NRI Property Mutation

```
If Owner is NRI:
- Apply through POA holder
- General or Specific POA
- Attestation from embassy
- Same documents otherwise
```

### Deceased Owner (Succession)

```
Steps:
1. Obtain death certificate
2. Get legal heir certificate
3. All heirs apply or consent
4. Succession certificate if required
5. Standard mutation process
```

### Agricultural to Non-Agricultural

```
Land Conversion Plus Mutation:
- First get NA permission
- Then apply for mutation
- Different authorities
- Additional fees for conversion
```

## Conclusion

Property mutation is a critical step after any property transaction. While registration transfers ownership, mutation updates government records and is necessary for practical purposes like paying taxes and future transactions.

**Key Takeaways:**

1. **Separate from registration**—mutation is additional step
2. **Apply promptly**—after registration or inheritance
3. **Complete documentation**—prevents delays
4. **Field verification**—cooperate with officials
5. **Track progress**—follow up regularly
6. **Handle objections**—respond with evidence
7. **Get updated records**—after mutation completes
8. **Update all services**—tax, utilities, etc.

**Don't Skip Mutation:**
- Future sale becomes difficult
- Tax notice may go to old owner
- Loan processing affected
- Title disputes possible
